# Changelog

## 0.4.1 — 2026-11-21

* `nftables` и `kmod-nft-tproxy` убраны из `DEPENDS` пакета: в OpenWrt SDK это
  тянет сборку модулей ядра и CI вместо ~10 минут работает 25+. Их ставит
  установщик (`install_deps`) — на роутере они уже собраны в фиде.
## 0.4.0 — 2026-11-21

* **geo-файлы едут в пакете** (`/usr/share/xray/{geoip,geosite}.dat`, ~0.5 МБ):
  после установки маршрутизация по спискам RoscomVPN работает сразу, без
  скачивания через прокси и без похода на CDN. Обновление — вручную
  `shoulderx geo` или вместе с пакетом.
* `geo_ttl=0` по умолчанию: автообновление geo отключено, чтобы сборка конфига
  не висела на таймаутах в сети без доступа к CDN.
* Пакет тянет всё нужное для прозрачного прокси: `nftables`,
  `kmod-nft-tproxy` (плюс прежние `ucode*`, `curl`, `ca-bundle`).
* Установщик ставит зависимости сам (`install_deps`), проверяет geo-файлы
  (`ensure_geo`) и при их отсутствии берёт из релиза.
* Подписка качается с повтором без проверки TLS, если часы роутера врут
  (`curl` → `curl -k`), с записью в лог.
## 0.3.5 — 2026-11-21

* Установщик сам ставит `curl` и `ca-bundle`, если их нет на роутере (раньше
  просто падал в wget с битым TLS).
* Перед скачиванием Xray — проверка сети: один запрос за `SHA256SUMS`, результат
  переиспользуется при установке пакетов; если релиз недоступен, об этом
  сообщается сразу, а не на середине.
* В зависимостях пакета `curl` и `ca-bundle` были и остаются — установщик
  страхует случай, когда пакеты ещё не стоят.
## 0.3.4 — 2026-11-21

* Сырые ошибки TLS (`curl: (60) mbedTLS…`, `SSL verify error`) больше не сыпятся
  в консоль: первая попытка идёт тихо, при неудаче печатается одна понятная
  строка с часами роутера и переход на загрузку без проверки TLS.
## 0.3.3 — 2026-11-21

* Если в фиде OpenWrt есть xray-core ровно запиненной версии (сейчас 26.10.21),
  установщик ставит пакет и **не качает 14 МБ через прокси** — на медленных
  каналах это было главной причиной «зависания». Загрузка архива осталась
  запасным путём (`--xray-from-upstream`, либо если версия в фиде другая).
## 0.3.2 — 2026-11-21

* Исправлены ANSI-коды в выводе: цвета печатались как `\033[36m`
  (printf `%s` не раскрывает escape-последовательности — теперь `%b`).
* Загрузка больше не «висит»: на каждую попытку лимит `SHOULDERX_DL_TIMEOUT`
  (240 с) через `timeout`, прогресс виден, перед крупными файлами пишется размер.
* При переборе зеркал видно, к какому идёт обращение.
## 0.3.1 — 2026-11-21

* Установщик работает, когда GitHub недоступен: адреса релиза качаются через
  прокси-зеркала (`gh-proxy.com`, `ghfast.top`, `ghproxy.net`) с автоматическим
  перебором, свой префикс — `--mirror=` или `SHOULDERX_MIRROR`.
* Откат на загрузку без проверки TLS для прошивок с битым ca-bundle
  (целостность держится на sha256 из релиза), поддержка `uclient-fetch`.
* Предупреждение, если часы роутера врут (ломает проверку сертификатов).
## 0.3.0 — 2026-11-21

Первый публичный релиз: установка одной строкой, Xray в комплекте.

**Установка**
* `installer/shoulderx-install.sh` — проверка платформы (OpenWrt, архитектура,
  `apk`/`opkg`, место), установка пакетов из последнего релиза со сверкой
  `SHA256SUMS`, настройка подписки/режима, первая сборка конфига.
* Xray ставится по цепочке: архив из релиза → upstream XTLS (пин + sha256) →
  пакет из фида. Версия закреплена (`26.10.21`).
* `.apk` (SDK 25.12) и `.ipk` (SDK 24.10) собираются в CI, релиз по тегу `v*`.

**Маршрутизация**
* Профиль RoscomVPN: блок-листы (`win-spy`, `torrent`, `category-ads`),
  приоритетный туннель (YouTube, Telegram, ChatGPT/Claude, Meta, X, Discord,
  GitHub), белые списки РФ напрямую (`geosite`+`geoip`), остальное в туннель.
* Отказ от allow-domains: маршрут целиком на `geoip.dat`/`geosite.dat`,
  скачиваются через туннель (`shoulderx geo`).
* Режимы: `lte` (обход БС) и `wifi` (домашний интернет) с секциями `yt` и `eu`.
* Фильтры групп узлов в LuCI (`LTE` / `WiFi`), регистронезависимые, включая
  кириллицу. Исключения секции `eu` (Россия) захардкожены.
* Балансировщики `leastPing` + `observatory`, `fallbackTag: direct` — если все
  узлы мертвы, LAN остаётся с интернетом.

**Прозрачный прокси (без podkop)**
* `nft` tproxy + policy routing для LAN, DNS клиентов через туннель,
  отключение IPv6 и flow-offloading на время работы, QUIC мимо tproxy.
* Сторож в cron: падение Xray или DNS снимает правила и возвращает резолвер.
* tproxy включается только после того, как балансировщики выбрали узлы.

**Подписки**
* Remnawave JSON (UA Happ + `x-hwid`) и share-ссылки `vless://`/`trojan://`
  (share-ссылки), несколько ссылок сразу, отсев заглушек по лимиту устройств.

**LuCI**
* Одна страница: подписка, режим, фильтры, плитки серверов с пингом и
  выбранным узлом, тест сервисов карточками, диагностика под спойлером.
* Применение — кнопкой: модалка с фазами (`подписка → geo → конфиг`),
  фоновая пересборка (`apply --async`), уведомления закрываются сами.

**CLI**
* `shoulderx apply|gen|fetch|list|check|nodes|state|autostart|service|tproxy|geo|mode|status|schedule`.
